# AI Code Explainer

Paste any code snippet and get a professional breakdown: line-by-line explanation, time/space complexity, dry run, Mermaid flowchart, and bug/improvement suggestions.

## Tech Stack

- **Backend:** Python FastAPI
- **LLM:** Claude API (Anthropic)
- **Frontend:** Single-page HTML/JS (no build step) — swap in React later if you want
- **Diagrams:** Mermaid.js

## Project Structure

```
ai-code-explainer/
├── backend/
│   ├── main.py              # FastAPI app entrypoint
│   ├── routers/
│   │   └── explain.py       # POST /explain endpoint
│   ├── services/
│   │   └── llm_client.py    # Claude API call + system prompt
│   ├── models/
│   │   └── schemas.py       # Pydantic request/response models
│   ├── requirements.txt
│   └── .env.example
└── frontend/
    └── index.html           # Single-file UI, opens directly in browser
```

## Setup

### 1. Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Edit `.env` and add your Anthropic API key:

```
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-sonnet-4-6
CORS_ORIGINS=http://localhost:5500,http://127.0.0.1:5500,null
```

Run the server:

```bash
uvicorn main:app --reload --port 8000
```

API docs available at `http://localhost:8000/docs` (auto-generated by FastAPI).

### 2. Frontend

Serve the frontend from a local static server so the configured CORS origins apply:

```bash
cd frontend
python -m http.server 5500
```

Then open `http://localhost:5500`. The frontend is still a no-build single-page app.

If your backend runs on a different host/port, update `API_BASE` at the top of the `<script>` block in `index.html`.
Set `CORS_ORIGINS` to the deployed frontend origin(s), separated by commas.

## API

**POST** `/explain`

Request body:
```json
{
  "code": "for(int i=0; i<n; i++){\nsum += arr[i];\n}",
  "language_hint": "cpp"
}
```

Response: structured JSON with `language_detected`, `line_by_line_explanation`, `time_complexity`, `space_complexity`, `dry_run`, `flowchart_mermaid`, `bugs_and_suggestions`, and `summary`.
